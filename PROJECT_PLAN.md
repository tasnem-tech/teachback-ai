# 7-day polish plan

## Day 1
Run the app locally. Test sample notes. Create a new GitHub repository and commit the initial version.

## Day 2
Test with 3 real university topics. Fix concept extraction edge cases. Improve labels and wording.

## Day 3
Add PDF/text-file upload if time permits. Do not sacrifice reliability for extra features.

## Day 4
Deploy to Streamlit Community Cloud. Test on phone and laptop.

## Day 5
Ask 2 people to use it without instructions. Fix anything they find confusing.

## Day 6
Record the 2-minute demo using the supplied script. Keep it under 1:55 to be safe.

## Day 7
Finish Devpost text, screenshots, README, repository cleanup, and final submission.

## Highest-value optional upgrades
1. PDF upload.
2. Speech-to-text teach-back.
3. Multilingual explanation mode.
4. Spaced repetition persistence.

Do not add all four unless the base app is already stable.
